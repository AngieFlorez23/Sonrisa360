# Sonrisa360

**Sistema de Gestión de Consultorio Odontológico**

Sonrisa360 es una aplicación web desarrollada como proyecto académico para facilitar la administración de un consultorio odontológico.

## Funcionalidades
- Registro e inicio de sesión de usuarios.
- Gestión de pacientes y odontólogos.
- Administración de consultorios.
- Agendamiento y seguimiento de citas.
- Gestión de cotizaciones.

## Tecnologías utilizadas
- **Backend:** Python y Django.
- **Base de datos:** PostgreSQL en Neon.
- **Alojamiento web:** Render.
- **Control de versiones:** GitHub.
